# How to run — Raw Node HTTP Server

Pure Node.js, no dependencies. Requires **Node.js 18+**.

## Windows (PowerShell)
```powershell
cd modules\02-backend-api\01-raw-node-http\solution
npm run dev
```

## macOS / Linux (Terminal)
```bash
cd modules/02-backend-api/01-raw-node-http/solution
npm run dev
```

Open **http://localhost:3000/products**. Stop with **Ctrl + C**.
