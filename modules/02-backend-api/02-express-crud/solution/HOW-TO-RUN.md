# How to run — Express CRUD API

Express API with in-memory data. Requires **Node.js 18+**.

## Windows (PowerShell)
```powershell
cd modules\02-backend-api\02-express-crud\solution
npm install
npm run dev
```

## macOS / Linux (Terminal)
```bash
cd modules/02-backend-api/02-express-crud/solution
npm install
npm run dev
```

API runs on **http://localhost:3000**. Test the routes with Thunder Client / Postman.
Stop with **Ctrl + C**.
