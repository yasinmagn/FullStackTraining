# How to run — React Shop (Vite)

A Vite + React app that fetches from your backend API. Requires **Node.js 18+**.

> **Start the API first.** This app calls `http://localhost:3000`. Run the backend
> from `modules/02-backend-api/04-auth-jwt/solution` (or the final-project backend)
> on port 3000 before starting this app.

## Windows (PowerShell)
```powershell
cd modules\04-frontend-framework\01-react-shop\solution
npm install
npm run dev
```

## macOS / Linux (Terminal)
```bash
cd modules/04-frontend-framework/01-react-shop/solution
npm install
npm run dev
```

Open the printed URL (usually **http://localhost:5173**). Stop with **Ctrl + C**.
