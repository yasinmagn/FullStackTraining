# How to run — static site (no build step)

This lesson is plain HTML/CSS/JS. Just open the page in a browser.

## Windows (PowerShell)
```powershell
cd 01-static-frontend\03-javascript-fundamentals\solution
start index.html
```

## macOS (Terminal)
```bash
cd 01-static-frontend/03-javascript-fundamentals/solution
open index.html
```

## Linux (Terminal)
```bash
cd 01-static-frontend/03-javascript-fundamentals/solution
xdg-open index.html
```

Tip: for auto-refresh while editing, open the folder in VS Code and use the
**Live Server** extension ("Go Live") instead of opening the file directly.
