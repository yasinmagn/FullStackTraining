# Module 01 — Static Frontend

**HTML · CSS · JavaScript · DOM**

In this module you build the SooqOnline storefront as a static website — no server
yet. You start with a semantic HTML skeleton, style it into a responsive shop with
CSS, add the shop's core logic in plain JavaScript, and finally make the page
interactive with the DOM: a live-searchable product grid and a working cart.

## Learning objectives

By the end of this module you will be able to:

- Structure a page with semantic HTML5 and accessible markup.
- Build responsive layouts with CSS Flexbox and Grid.
- Write core JavaScript: arrays, objects, functions, `find` / `filter` / `map` / `reduce`.
- Render UI from data and respond to user events with the DOM API.

## How each unit works

Each unit folder has:
- `README.md` — the lesson (objectives, tasks, verify checklist).
- `starter/` — copy this and complete the numbered TODOs.
- `solution/` — the complete reference once you're done (or stuck).

Work through the units in order — each starter builds on the previous solution.
